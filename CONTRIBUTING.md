# Contributing to StudyHawk

Pull requests are welcome: fixes, features, translations, docs and designs.

## Before you start

- For anything bigger than a small fix, open an issue first so we can agree on the approach.
- Read [README.md](README.md) to run the project locally, and [SECURITY.md](SECURITY.md). Report vulnerabilities to
  security@studyhawk.app, not in a public issue.
- Keep changes focused: one topic per pull request, with tests where the code has them.
